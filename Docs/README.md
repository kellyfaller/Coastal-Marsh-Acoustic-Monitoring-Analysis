# Documentation

This folder contains the acoustic monitoring project manual and support documents.

## Files
- `Acoustics_Manual_v2.0.pdf`: Current published manual
- `CHANGELOG.md`: Version history and changes
- `Github_Repository_Structure.docx`: Script and file management structure
- `CITATION.cff`: Citation for giving credit for the code and works located in this repository
- `SOPs/`: Standard operating procedures useful for acoustic monitoring

## Versioning
We follow semantic versioning. See `CHANGELOG.md` for release notes.
